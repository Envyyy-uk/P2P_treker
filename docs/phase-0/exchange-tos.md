# Перевірка Terms of Service бірж (Фаза 0, п.13)

Порушення умов біржі може призвести до блокування акаунту незалежно від
якості коду. Перед підключенням реальних акаунтів (навіть read-only)
пройти цей чеклист для **кожної** біржі й зафіксувати дату перевірки.

## Що перевірити

- [ ] Чи дозволена автоматизована торгівля / API-боти для звичайних акаунтів.
- [ ] Чи доступна біржа (spot API + WebSocket) у вашому регіоні/юрисдикції.
- [ ] Ліміти API (rate limits, кількість WS-підключень, кількість підписок).
- [ ] Чи потрібен окремий тип акаунту / KYC-рівень для API-доступу.
- [ ] Правила щодо кількох акаунтів (якщо плануються dev/staging/prod ключі).
- [ ] Чи є заборони на специфічні патерни (high-frequency, market making без статусу).
